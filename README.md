# Kyla Fitzpatrick — Portfolio

Personal portfolio of Kyla Fitzpatrick, Software Engineer & Web Developer.

**Live site:** https://kylafitzpatrick.github.io/KylaFitzpatrick/

## Highlights

- Kinetic hero with masked line-by-line reveal and mouse-follow parallax
- Selected work: live screenshot cards for production websites (chillflows.com, gracreation.com, bloomerslkn.com) with quick-view previews
- On-page resume with PDF download and print support
- Skills & technologies, manifesto, and contact sections
- Smooth momentum scrolling (Lenis) and scroll reveals (Framer Motion)
- Fully responsive — desktop, tablet, and mobile

## Tech Stack

React (CRA + Craco) · Tailwind CSS · Framer Motion · Lenis · lucide-react · sonner

## Development

```bash
cd frontend
yarn install
yarn start
```

## Build & Deploy (GitHub Pages)

```bash
cd frontend
PUBLIC_URL=/KylaFitzpatrick yarn build
```

Deploys automatically via GitHub Actions (`.github/workflows/deploy-pages.yml`) on every push to `main`.
